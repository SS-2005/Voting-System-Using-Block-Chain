Academic Demonstration Notice & Security Scope

🧪 Educational Prototype

This project demonstrates decentralized state management on Ethereum. It uses a local Hardhat testnet with simulated ETH and no real monetary value.

🔍 On-Chain Transparency

All votes and transactions are permanently stored in smart contract storage and emitted in events, making the count publicly auditable and tamper-evident.

🛡️ Wallet Identity Scope

Authorizing an address guarantees one vote per authorized keypair, but does not provide real-world biometric sybil resistance or identity binding.
